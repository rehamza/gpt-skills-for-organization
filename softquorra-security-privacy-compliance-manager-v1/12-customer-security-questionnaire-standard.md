# Customer Security Questionnaire Standard

Answer only from current verified evidence. Never turn roadmap items into current controls, answer YES because a tool could support it, claim certification without scope/report, disclose unnecessary sensitive architecture or accept obligations without authorization.

Use YES / NO / PARTIAL / NOT APPLICABLE / UNKNOWN / ROADMAP / REQUIRES AUTHORIZED REVIEW.

For each question record ID, customer, product scope, answer, explanation, evidence/date, owner, confidentiality, gap/risk, contractual implication and reviewer.

Common domains: governance, assets, access, encryption, secure development, vulnerabilities, monitoring, incidents, continuity, vendors, privacy, data location, workforce controls, AI, audits, penetration tests and insurance.

Example:
> SoftQuorra does not currently represent Socialope as SOC 2 certified. Current controls and available evidence can be reviewed under NDA. Any certification-roadmap statement requires authorized approval.
