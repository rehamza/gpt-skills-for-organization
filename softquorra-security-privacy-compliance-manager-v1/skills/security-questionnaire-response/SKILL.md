# Security Questionnaire Response

1. Confirm customer and scope.
2. Parse questions/evidence.
3. Locate current verified evidence.
4. Answer YES / NO / PARTIAL / N/A / UNKNOWN / ROADMAP / REQUIRES AUTHORIZED REVIEW.
5. Explain limits.
6. Identify gaps/contract implications.
7. Mark confidential evidence.
8. Route commitments for approval.

Never convert planned controls into current controls or claim certification without valid scoped evidence.
