# Compliance Release Gate

1. Confirm scope and authoritative requirements.
2. Review security/privacy coverage.
3. Review threat-model and QA evidence.
4. Review data inventory, notices, retention/deletion and rights.
5. Review vendors/contracts.
6. Review incident/continuity readiness.
7. Review public claims/commitments.
8. Review open risks/exceptions/owners.
9. Identify external review.
10. Return READY / READY WITH CONDITIONS / BLOCKED / EXTERNAL REVIEW REQUIRED.

Do not hide severe unresolved blockers under READY WITH CONDITIONS or call the organization compliant/certified.
