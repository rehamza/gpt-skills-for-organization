# Data Processing Inventory

1. Define activity/system.
2. Identify subjects/categories/source/purpose.
3. Separate required vs optional data.
4. Map collection, transfer, storage, use, disclosure and deletion.
5. Identify systems/vendors/locations.
6. Identify access and controls.
7. Record retention/deletion/backups.
8. Identify rights and incident impact.
9. Flag privacy-role/legal-basis/notice questions.

Output table: Activity | Subjects | Data | Source | Purpose | Systems/vendors | Access | Retention/deletion | Transfer | Security | Role questions | Owner.

Do not treat missing data as not collected or invent a lawful basis.
