# Vendor & Subprocessor Review

1. Identify vendor/service/owner.
2. Map use and data/system access.
3. Identify locations/subprocessors.
4. Review current official evidence.
5. Review retention/deletion/training/data use/incident terms.
6. Review permissions, availability and continuity.
7. Review DPA/contract/transfer questions.
8. Identify gaps/conditions.
9. Return decision/review date.

Decision: APPROVED / APPROVED WITH CONDITIONS / PILOT ONLY / BLOCKED / EXTERNAL REVIEW REQUIRED.

Marketing claims alone are not approval evidence.
