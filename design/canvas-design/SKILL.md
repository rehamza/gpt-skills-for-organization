# Canvas Design

Create only `.md`, `.pdf`, and `.png` outputs. Work in two phases:

1. Create a design philosophy as a `.md` file.
2. Express that philosophy visually as a `.pdf` or `.png` canvas.

## Design Philosophy Creation

Create a visual philosophy, not a layout or template. Treat the user's input as subtle foundation material that informs the work without constraining creative freedom. The output of this phase is an aesthetic movement that can be interpreted through form, space, color, composition, images, graphics, shapes, patterns, and minimal text as visual accent.

The philosophy must emphasize visual expression, spatial communication, artistic interpretation, and minimal words. Think like an art-movement manifesto. Information should live in design decisions, not paragraphs of explanatory copy.

Name the movement in one or two words, such as `Brutalist Joy`, `Chromatic Silence`, or `Metabolist Dreams`. Then write four to six concise but substantial paragraphs describing how the philosophy manifests through space and form, color and material, scale and rhythm, composition and balance, and visual hierarchy.

Avoid redundancy. Mention each design aspect once unless adding new depth. Leave enough creative space for the next agent to make interpretive choices at an extremely high level of craftsmanship.

Repeatedly emphasize craftsmanship. The philosophy must stress that the final work should appear meticulously crafted, labored over with care, and produced with master-level execution by someone at the top of their field. Use ideas like painstaking attention, deep expertise, countless hours of refinement, and expert composition.

Keep the philosophy generic enough that it can be used anywhere. Do not overfit it to the immediate subject. Output the design philosophy as a `.md` file.

## Philosophy Examples

**Concrete Poetry**
Philosophy: Communication through monumental form and bold geometry.
Visual expression: Massive color blocks, sculptural typography, huge single words, tiny labels, Brutalist spatial divisions, and Polish poster energy meeting Le Corbusier. Ideas are expressed through visual weight and spatial tension, not explanation. Text is a rare, powerful gesture: never paragraphs, only essential words integrated into the visual architecture. Every element is placed with master-craft precision.

**Chromatic Language**
Philosophy: Color as the primary information system.
Visual expression: Geometric precision where color zones create meaning. Typography is minimal, with small sans-serif labels letting chromatic fields communicate. Think Josef Albers interaction meets data visualization. Information is encoded spatially and chromatically. Words only anchor what color already shows. The result is built through painstaking chromatic calibration.

**Analog Meditation**
Philosophy: Quiet visual contemplation through texture and breathing room.
Visual expression: Paper grain, ink bleeds, and vast negative space. Photography and illustration dominate. Typography is whispered: small, restrained, serving the visual. Use a Japanese photobook sensibility where images breathe across the page. Text appears sparingly as short phrases, never explanatory blocks. Each composition is balanced with meditative care.

**Organic Systems**
Philosophy: Natural clustering and modular growth patterns.
Visual expression: Rounded forms, organic arrangements, and color drawn from nature through architecture. Information is shown through visual diagrams, spatial relationships, and iconography. Text appears only as key labels floating in space. The composition tells the story through expert spatial orchestration.

**Geometric Silence**
Philosophy: Pure order and restraint.
Visual expression: Grid-based precision, bold photography or stark graphics, and dramatic negative space. Typography is precise but minimal, with small essential text and large quiet zones. Swiss formalism meets Brutalist material honesty. Structure communicates instead of words. Every alignment looks refined countless times.

## Subtle Reference

Before creating the canvas, identify the subtle conceptual thread from the original request.

The topic should become a subtle, niche reference embedded within the art itself. It should not always be literal. It should be sophisticated enough that someone familiar with the subject feels it intuitively, while others simply experience a masterful abstract composition.

Use the design philosophy as the aesthetic language and the deduced topic as the conceptual DNA woven quietly into form, color, and composition. Think like a musician quoting another song: only those who know will catch it, but everyone should appreciate the piece.

## Canvas Creation

With the philosophy and conceptual framework established, express the work on a canvas. Use the design philosophy as the foundation and produce one single-page, highly visual, design-forward PDF or PNG unless the user asks for more pages.

For any subject, including a movie, game, book, or pop-culture request, keep the work sophisticated. Make art, not something cartoonish or amateur. Generally use repeating patterns and precise shapes. Treat the abstract design as if it were a scientific artifact: dense accumulated marks, repeated elements, layered patterns, sparse clinical typography, and systematic reference markers that suggest an imaginary discipline studying an invisible subject.

Use visual systems to express human experience. Anchor the piece with simple phrases or subtle details, and use a limited palette that feels intentional and cohesive. The result should feel like an artifact proving something ephemeral can be studied, mapped, and understood through careful attention.

Text must be minimal and visual-first, but context determines whether it appears as whisper-quiet labels or bold typographic gestures. A punk venue poster may use larger, more aggressive type than a minimalist ceramics studio identity. Most of the time, prefer thin fonts. Typography must be design-forward and integrated into the art.

If a `./canvas-fonts` directory exists, inspect it before choosing fonts. If it does not exist, use available system or project fonts, or download fonts only when the environment allows it. Use different fonts when writing text if that improves the visual system. Regardless of the approach, sophistication is non-negotiable.

Keep every element inside the canvas boundaries with proper margins. Nothing should fall off the page, collide, or overlap incoherently. Text, graphics, and visual elements need breathing room and clear separation. Verify spacing, containment, and visual hierarchy before delivering the final file.

Push the aesthetics to the frontier while respecting the philosophy. Make the work look human-crafted, as if someone at the absolute top of the field labored over every detail for countless hours. Composition, spacing, color, typography, and finishing details should all show painstaking care and master-level execution.

Output the final result as a single downloadable `.pdf` or `.png` file, alongside the `.md` design philosophy used.

## Final Pass

Assume the user has already said: "It isn't perfect enough. It must be pristine, a masterpiece of craftsmanship, as if it were about to be displayed in a museum."

Take a second pass. Refine what exists instead of reflexively adding more graphics. Make the composition crisper, more cohesive, and more philosophically resolved. If the instinct is to draw another shape or add an effect, pause and ask how the existing composition can become more complete as art.

## Multi-Page Option

When the user requests additional pages, create more pages within the same design philosophy while making each page distinctly different. Bundle the pages in one `.pdf` or export multiple `.png` files. Treat the first page as one page in a larger coffee-table book. Let later pages become unique variations and memories of the original, almost telling a story in a tasteful way.
