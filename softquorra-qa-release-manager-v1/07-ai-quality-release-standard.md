# AI Quality Release Standard

For each AI workflow test as relevant:
- task success
- schema validity
- correctness/relevance
- groundedness
- hallucination/fabrication
- tool selection/tool success
- permission boundaries
- human approval
- fallback
- timeout/provider failure
- prompt/model regression
- latency
- cost
- safety/abuse
- tenant/privacy isolation

Use representative normal, edge, adversarial, and failure cases.

Compare against approved release thresholds or baselines.
Do not invent thresholds.
