# Bug Severity & Triage

## Critical
Catastrophic security/data/payment/availability issue or core product unusable with no acceptable workaround.

## High
Major P0 workflow failure, serious data/integration issue, or material user impact.

## Medium
Important but limited failure with workaround or non-core impact.

## Low
Minor cosmetic/usability/content issue with limited impact.

Severity != implementation effort.

Defect record:
- ID
- title
- environment/build
- requirement
- preconditions
- steps
- expected
- actual
- evidence
- severity
- impact
- workaround
- regression scope
- release impact
- owner/status
