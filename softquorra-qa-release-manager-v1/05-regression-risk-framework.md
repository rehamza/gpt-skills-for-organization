# Regression Risk Framework

Inspect change impact across:
- directly changed feature
- shared components/modules
- database/schema
- API contracts
- auth/permissions
- integrations/webhooks
- jobs/queues
- billing
- analytics
- AI prompt/model/tool/retrieval
- config/deployment
- mobile/platform behavior

Classify regression risk:
LOW / MEDIUM / HIGH / CRITICAL

Build targeted regression from the impact map.
