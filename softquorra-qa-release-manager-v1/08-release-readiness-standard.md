# Release Readiness Standard

Review:
- P0 verification
- P1/P2 exclusions preserved
- open defects
- security
- data/migrations
- integrations
- AI quality
- analytics/observability
- backup/recovery where relevant
- deployment plan
- rollback/forward-fix
- feature flags/cohorts
- support/incident owner
- known limitations
- accepted risks

Decisions:
GO
CONDITIONAL GO
NO-GO

Conditional GO requires explicit conditions, owner, monitoring, and rollback/mitigation.
Critical unresolved blockers mean NO-GO.
