# Regression Risk Analysis
Inspect direct change plus shared dependencies.
Classify LOW / MEDIUM / HIGH / CRITICAL.
List affected workflows and targeted regression tests.
Include backward compatibility, migration, integration, and config risk.
Avoid broad full-suite recommendations when targeted evidence is sufficient.
