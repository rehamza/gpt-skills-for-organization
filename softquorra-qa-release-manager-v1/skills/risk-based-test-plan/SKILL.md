# Risk-Based Test Plan
1. Identify changed behavior and critical journeys.
2. Identify failure modes and impact.
3. Rank risk.
4. Choose relevant functional, integration, E2E, migration, security, accessibility, AI, performance, failure, and smoke coverage.
5. Define data/environment needs.
6. Map tests to requirements.
7. Define release blockers and exit criteria.
Do not create every test type for every feature.
