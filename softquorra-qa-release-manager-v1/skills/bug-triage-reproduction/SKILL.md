# Bug Triage & Reproduction
1. Capture environment/build and requirement.
2. Reproduce with minimal reliable steps.
3. Record expected vs actual and evidence.
4. Assess user/business/security/data impact.
5. Assign Critical/High/Medium/Low severity.
6. Define release impact and workaround.
7. Define regression tests required after fix.
8. Produce QA FIX HANDOFF for Codex when code change is needed.
Severity is based on impact, not fix difficulty.
