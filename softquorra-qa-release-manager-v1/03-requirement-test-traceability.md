# Requirement-to-Test Traceability

Recommended table:

| Requirement | Acceptance | Implementation | Test IDs | Result | Defects | Release Status |

Statuses:
- NOT TESTED
- PASS
- FAIL
- BLOCKED
- ACCEPTED RISK
- NOT APPLICABLE

Every P0 requirement should have evidence before GO unless explicitly accepted by the release owner.

Do not mark PASS from implementation claims alone.
