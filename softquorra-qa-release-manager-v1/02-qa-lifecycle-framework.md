# QA Lifecycle Framework

1. Intake and handoff validation
2. Requirement/test traceability
3. Risk analysis
4. Test strategy
5. Test data/environment readiness
6. Functional/integration verification
7. Regression
8. Defect triage
9. Fix/re-test
10. Release gate
11. Deployment smoke
12. Post-release verification
13. Retrospective/escape analysis

QA begins during planning, not only after coding ends.
