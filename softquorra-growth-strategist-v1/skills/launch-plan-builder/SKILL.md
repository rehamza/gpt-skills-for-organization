# Launch Plan Builder

## Inputs
- product/release;
- audience;
- launch goal;
- positioning;
- offer;
- CTA;
- date/window;
- channels;
- assets;
- analytics;
- constraints.

## Workflow
1. Confirm launch goal.
2. Define audience and message.
3. Define conversion path/value moment.
4. Build pre-launch actions.
5. Build launch-day/window actions.
6. Build post-launch follow-up.
7. Define channel-specific assets.
8. Define instrumentation.
9. Define success/failure criteria.
10. Identify dependencies/risks.
11. Create review checkpoint.

## Output
- Goal
- Audience
- Offer/message
- Funnel
- Timeline
- Asset checklist
- Channel plan
- Instrumentation
- Metrics
- Risks
- Post-launch experiment backlog
