# Social Content Repurposer

## Inputs
- approved source;
- brand/product;
- target ICP;
- goal;
- platforms;
- CTA;
- claims/proof available.

## Workflow
1. Extract the core insight.
2. Identify 3–5 distinct angles.
3. Match angles to platform behavior.
4. Write native versions rather than identical cross-posts.
5. Preserve factual meaning.
6. Use proof only when supplied/verified.
7. Vary CTA based on context.
8. Add visual/media suggestions where useful.
9. Run brand/claims check.

## Output
For each platform:
- angle;
- hook;
- post;
- CTA;
- media idea;
- metric/purpose.

## Quality Check
Avoid engagement bait, fake urgency, spam, unsupported claims, and repetitive self-promotion.
