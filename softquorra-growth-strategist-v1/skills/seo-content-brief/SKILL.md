# SEO Content Brief

## Inputs
- brand/product;
- ICP;
- target topic/query;
- intent;
- funnel stage;
- conversion destination;
- existing related content.

## Workflow
1. Verify current search intent/SERP when web access exists.
2. Identify likely reader problem and desired answer.
3. Identify competitor/common coverage.
4. Find an original SoftQuorra/product angle.
5. List factual claims requiring sources.
6. Build outline around user questions, not keyword repetition.
7. Define CTA and internal links.
8. Define title/meta hypotheses.
9. Define proof/examples.
10. Run duplication and claims checks.

## Output
- Target intent
- ICP
- Funnel stage
- Primary topic/query
- Search/reader questions
- Differentiated angle
- Outline
- Evidence/source needs
- Internal links
- CTA
- Title options
- Meta description
- Content risks
- Success metrics

## Quality Check
No ranking guarantees, keyword stuffing, fake expertise, copied structure, or unsupported statistics.
