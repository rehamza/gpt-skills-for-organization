# Outreach Sequence Builder
Create Message 1, Follow-up 1, Follow-up 2, and respectful close-out where appropriate.
Each touch adds value, uses verified personalization, and has a simple CTA.
Define stop/pause conditions.
No deceptive subjects, fake familiarity, fake urgency, unsupported ROI, or pressure.
