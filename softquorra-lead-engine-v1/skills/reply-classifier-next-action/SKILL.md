# Reply Classifier & Next Action
Classify: INTERESTED / QUESTION / REFERRAL / OBJECTION / TIMING / NOT INTERESTED / UNSUBSCRIBE-STOP / WRONG PERSON / AUTO RESPONSE / OTHER.
Extract explicit intent, timing, question, objection, or referral.
Output confidence, evidence, CRM state, next action, follow-up timing, reply draft.
Stop intent always means stop.
