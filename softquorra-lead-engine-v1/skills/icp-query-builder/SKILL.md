# ICP Query Builder
1. Restate the ICP operationally.
2. Identify observable account signals.
3. Build company/category, geography, buyer, trigger, workflow/technology, hiring, pain, and competitor query lanes.
4. Explain what each query finds and how it supports qualification.
5. Rank the best first searches.
Output a table: Priority | Query | Lane | Signal | Qualification use.
Do not broaden ICP just to get more results.
