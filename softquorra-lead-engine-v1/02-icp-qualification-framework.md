# ICP Qualification Framework
Define observable criteria:
- industry/category
- geography
- size/maturity if relevant
- business model
- workflow/tooling
- trigger
- buyer function
- problem context
- positive signals
- exclusions/disqualifiers

Classify:
QUALIFIED / POSSIBLE / DISQUALIFIED / INSUFFICIENT DATA

Missing data is not positive evidence.

Optional scoring may use Fit + Trigger + Buyer relevance + Problem evidence + Commercial fit, with explained weights.
